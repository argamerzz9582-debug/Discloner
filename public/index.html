    Migration guide & setup

    Everything you need before the first run.

    1. Get a user token. Open Discord in a browser, find the token in the app's local storage, and treat it like a password.
    2. Enable developer mode in Discord settings to copy server IDs from the context menu.
    3. Confirm permissions. Your account needs Manage Channels, Manage Roles, Manage Webhooks and Manage Server on the target.
    4. Run preflight. It verifies both servers and previews what cleanup will delete.
    5. Choose a mode. One-shot copies once; continuous mirror keeps forwarding until stopped.
    Account risk: automating a user account violates Discord's Terms of Service. Use a throwaway account on servers you own.
