Migration Guide & Requirements

1

Obtain Server IDs

Enable Developer Mode in Discord (Settings → Advanced → Developer Mode). Right-click on your source and target servers in Discord and select Copy Server ID.

2

Permissions Requirement

Your account must have Administrator or Manage Server permissions on the target server to create channels, roles, and webhooks.

3

Message History Synchronization

Messages are replicated via Discord webhooks with matching usernames and avatars. Set an appropriate message limit to match your needs.
