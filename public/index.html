Migration Guide & Setup

1

Enable Developer Mode in Discord

Go to Discord Settings → Advanced → Toggle Developer Mode ON. This allows you to right-click servers and copy their 17–20 digit Snowflake ID.

2

Account Permissions

Your Discord account must have Administrator or Manage Server / Manage Roles / Manage Channels permissions on the target server.

3

Message Synchronization (Optional)

Message cloning is OFF by default. If enabled in Advanced Settings, messages are replicated using Discord webhooks with original author names and avatars.
